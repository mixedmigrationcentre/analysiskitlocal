# Accept a List of Analysis as a Path or an Already-Read Workbook

Accept a List of Analysis as a Path or an Already-Read Workbook

## Usage

``` r
as_loa_workbook(loa)
```

## Arguments

- loa:

  A path, or the list from
  [`read_loa_workbook()`](https://mixedmigrationcentre.github.io/analysiskitlocal/reference/read_loa_workbook.md).

## Value

A workbook list.
