# Group-Wise Sums of a Numeric Vector

Group-Wise Sums of a Numeric Vector

## Usage

``` r
ck_gsum(values, g, levels_g)
```

## Arguments

- values:

  Numeric vector to sum.

- g:

  Group vector (character).

- levels_g:

  Group levels to report, in order.

## Value

A numeric vector, one element per level of `levels_g`.
