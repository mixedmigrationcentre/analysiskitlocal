# Summarise a Dataset

Summarise a Dataset

## Usage

``` r
dataset_overview(dataset)
```

## Arguments

- dataset:

  The list returned by
  [`read_analysis_dataset()`](https://mixedmigrationcentre.github.io/analysiskitlocal/reference/read_analysis_dataset.md).

## Value

A data frame with `Measure` and `Value`: file name, file type, file
size, rows, columns and completely duplicated rows.
