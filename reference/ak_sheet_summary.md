# Summarise Which Sheets a Workbook Supplied

Summarise Which Sheets a Workbook Supplied

## Usage

``` r
ak_sheet_summary(workbook)
```

## Arguments

- workbook:

  The list from
  [`read_loa_workbook()`](https://mixedmigrationcentre.github.io/analysiskitlocal/reference/read_loa_workbook.md).

## Value

A data frame with `Sheet`, `Rows` and `Status`.
