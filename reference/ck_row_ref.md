# Build an Excel Range Reference for a Single Row

Build an Excel Range Reference for a Single Row

## Usage

``` r
ck_row_ref(row, col_from, col_to)
```

## Arguments

- row:

  Row number.

- col_from:

  First column.

- col_to:

  Last column.

## Value

A range string, or `NA` when the range covers one cell.
